# 0001. HF 공부를 별도 저장소로 독립

- 날짜: 2026-11-12
- 상태: 채택

## 배경

처음에는 개인 AI 놀이터 저장소(`kdi0420/AI_playground`)의 `experiments/2026-11-12-hf-agents-course/`에 공부 폴더를 만들었다.
사용자가 "AI_playground 밑에 새 git을 만들어서 그 위치에서 할 수 없나?"라고 물었다.

## 검토한 선택지

| 선택지 | 판단 |
|---|---|
| AI_playground 안에 폴더로 유지 | 세션 기억·훅을 그대로 쓰지만, 장학금·항공권 등 다른 주제와 섞이고 현준과 공유하기 어렵다 |
| AI_playground 안에 중첩 `.git` | 클라우드 세션은 GitHub 저장소를 새로 복제하므로 안쪽 저장소는 사라진다. 서브모듈은 관리 부담이 크다 → 기각 |
| **별도 GitHub 저장소** | HF 공부만 있어 집중되고 공유가 쉽다. 세션 기억·훅·스킬은 복사해서 맞춘다 → **채택** |

## 결정

`kdi0420/hf_ai_study`를 HF 공부 전용 저장소로 쓴다.

- 공부 내용(진도표, 노트, 용어집, 질문, 퀴즈, 실습 requirements)을 옮기고, 유닛 폴더는 `units/` 아래로 모았다.
- AI_playground의 작업 규칙(AGENTS/CLAUDE), 세션 기억(`context/`), 훅(세션 시작 동기화, 턴 종료 autosave)을 HF 공부용으로 바꿔 가져왔다.
- 개인 민감정보(장학금, 이력서, 여행 일정 등)는 가져오지 않았다. 공유를 전제로 한다.
- AI_playground 쪽 실험 폴더에는 이 저장소를 가리키는 안내만 남긴다.

## 결과

- 클라우드 세션은 **이 저장소를 선택해서** 시작해야 이 규칙들이 로드된다.
- 두 저장소의 `context/USER.md`는 따로 관리된다. 공통 선호가 바뀌면 양쪽을 맞춘다.
