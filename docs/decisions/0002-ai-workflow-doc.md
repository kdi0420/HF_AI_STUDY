# 0002. AI 작업 절차 문서 추가

- 날짜: 2026-11-12
- 상태: 채택

## 배경

사용자는 개인 일정 관리 시스템에서 AI와 일하는 방식(승인 표, 후보고, '딸린 것' 점검, 대화에서 정한 것 바로 기록하기 등)을 다듬어 왔다.
그 방식 중 GitHub 레포에서도 통하는 것을, 개인정보 없이 이 레포에도 쓰고 싶어 했다.

## 검토한 선택지

| 선택지 | 판단 |
|---|---|
| 범용 매뉴얼을 루트에 그대로 올림 | `AGENTS.md`와 규칙 원천이 둘이 되고 폴더 구조·커밋 방식이 부딪친다. "루트에 새 파일 금지"에도 어긋난다 → 기각 |
| `AGENTS.md`에 전부 합침 | 원천은 하나로 남지만 "짧고 정확하게"가 깨진다 |
| **레포에 맞게 고쳐 `docs/`에 두고 `AGENTS.md`가 가리킴** | `AGENTS.md`는 짧게 유지하고, 승인·후보고·비밀 점검·Hub 절차의 세부만 따로 둔다 → **채택** |

## 결정

`docs/ai-workflow.md`를 추가하고, `AGENTS.md`의 디렉터리 지도와 규칙에 한 줄씩 그 문서를 가리키게 했다.

- 이 레포에 이미 정한 방식(autosave 자동 푸시, `/wrap-up`의 main 반영, `context/` 세션 기억)은 그대로 두고 승인 대상에서 뺐다.
- 승인 대상은 밖으로 나가거나 되돌리기 어려운 행동으로 좁혔다: Hub 쓰기, 공개 범위 변경, 삭제, `trust_remote_code`, 큰 다운로드, 유료 자원.
- autosave 때문에 비밀 점검은 "커밋 전"이 아니라 "파일에 쓰기 전"에 하게 했다.

## 결과

- 둘이 다르면 `AGENTS.md`가 우선이다.
- 한 줄 규칙은 `AGENTS.md`에, 세부 절차는 `docs/ai-workflow.md`에 둔다.
