# 사용자 프로필

AI가 이 사용자에게 맞춰 일하기 위한 메모. **매 세션 자동으로 로드된다** (`CLAUDE.md`에서 불러옴).

- AI는 대화에서 선호를 새로 알게 되면(명시적 요청, 교정, 반복되는 패턴) 이 파일을 갱신하고, 사용자에게 한 줄로 알린다.
- 사용자가 직접 고쳐도 된다. 사용자가 쓴 내용이 AI의 관찰보다 우선한다.
- 이 레포는 **공개 레포**이므로 실명(사용자·친구)과 민감한 개인정보(연락처, 계정, 건강, 재정, 여행·출국 일정, 장학금·이력서 등)는 적지 않는다. 친구는 "친구"로만 적는다.

## 소통

- 한국어로 대화한다. 코드 식별자·명령어는 영어 그대로.
- 결과 위주로 짧게 보고한다: 무엇을 했고, 검증됐는지, 내가 결정할 것이 무엇인지.

## 일하는 방식

- 짧은 지시로 큰 권한을 위임하는 편이다 ("알아서"). → **합리적인 기본값으로 먼저 진행**하고, 정말 사용자가 결정해야 하는 것만 묻는다.
- 세션 간 초기화 없이 이어서 일하길 원한다. → 상태는 항상 `context/STATUS.md`에 남긴다.
- Claude 앱의 클라우드 세션을 주로 쓴다. → 작업은 바로 push한다 (autosave 훅이 처리).
- 할 일은 Todoist로 관리한다 ("🤗 개인 › AI 공부" 섹션). → 진도·날짜는 Todoist와 맞춘다.

## 공부 맥락

- 대학 학부생. 친구와 HF AI Agents Course를 1주 1유닛, 주 3~4시간으로 공부 (2026-11-11 시작).
- 관심: 개인 AI 구동, 여러 AI 도구 실험, AI를 잘 쓰는 사람들의 방식(워크플로우·컨텍스트 관리). 장기적으로 리서치 자동화, GPT·Gemini 교차 검증 같은 에이전트를 만들고 싶어 한다.
- 코스를 끝내면 AI 공부 SNS 계정 운영도 고려 중 (Todoist 아이디어).
- 배경: 지금까지 배운 건 **수학 기반**이고 CS(터미널·Git·개발 환경·AI 구조)는 입문자라고 스스로 말함 → 개발 용어는 처음 나올 때 한 줄로 풀어 쓴다. 기초 질문 목록: `units/unit0-onboarding/beginner-questions.md`
- 기기: 노트북 + 집 데스크탑. 로컬 모델(Ollama 등)처럼 무거운 실습은 데스크탑에서 하려 함. 데스크탑: Windows, RAM 64GB, 전용 GPU 메모리 10GB.
- 공부 방식 선호(Todoist 메모): 영상보다 **AI에게 직접 물어보며** 배우기, 자기만의 청사진은 대화로 구축.
- 섹션 공부 흐름(2026-11-15): 사용자가 먼저 혼자 읽고 → 원문을 **복사해 붙여 주면** AI가 핵심 요약 → 사용자가 질문. 어려운 부분은 "입문자 레벨로 자세히" 다시 요청함 → 비유·작은 예시·표로 풀어 쓴다. **2026-11-15부터는 처음부터 입문자용 상세 설명이 기본**(짧은 요약 말고 "처음부터 쭉" 장별로)
- **데스크탑 실행 안내는 매번 처음부터 하나하나**(2026-11-16): PowerShell 창 열기 → `cd` 폴더 이동 → `.venv\Scripts\Activate.ps1` → `git pull` → 실행 명령까지 순서대로, 한 줄씩 코드 블록으로. "code 폴더에서 venv 켜고"처럼 줄여 말하지 않는다. 실습은 Jupyter 노트북으로 한 칸씩 실행·확인하는 방식을 좋아함
- **곁가지 질문 세션**(2026-11-22): 메인 공부 세션과 따로, 옆에서 궁금한 것만 묻는 세션을 열기도 한다 → 거기서는 질문에 답하고 `questions.md`·`glossary.md`에만 기록, STATUS·노트 등 메인 흐름 파일은 건드리지 않는다(동시 수정 충돌 방지)
- **실습은 AI가 이해하기 쉬운 노트북을 만들어 칸마다 설명**해 주면 그걸 바탕으로 해 본다(2026-11-22). 내용이 간단한 섹션은 실습을 건너뛰기도 함 → 실습이 필수인지 선택인지 짧게 알려 준다
- **답변 끝에 확인 질문·퀴즈를 던지지 않는다.** 사용자가 원할 때만 묻는다 (2026-11-12 요청).
