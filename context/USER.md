# 사용자 프로필

AI가 이 사용자에게 맞춰 일하기 위한 메모. **매 세션 자동으로 로드된다** (`CLAUDE.md`에서 불러옴).

- AI는 대화에서 선호를 새로 알게 되면(명시적 요청, 교정, 반복되는 패턴) 이 파일을 갱신하고, 사용자에게 한 줄로 알린다.
- 사용자가 직접 고쳐도 된다. 사용자가 쓴 내용이 AI의 관찰보다 우선한다.
- 이 레포는 **공개 레포**이므로 실명(사용자·친구)과 민감한 개인정보(연락처, 계정, 건강, 재정, 여행·출국 일정, 장학금·이력서 등)는 적지 않는다. 친구는 "친구"로만 적는다.

## 소통

- 한국어로 대화한다. 코드 식별자·명령어는 영어 그대로.
- 결과 위주로 짧게 보고한다: 무엇을 했고, 검증됐는지, 내가 결정할 것이 무엇인지.

## 일하는 방식

- 짧은 지시로 큰 권한을 위임하는 편이다 ("알아서"). → **합리적인 기본값으로 먼저 진행**하고, 정말 사용자가 결정해야 하는 것만 묻는다.
- 세션 간 초기화 없이 이어서 일하길 원한다. → 상태는 항상 `context/STATUS.md`에 남긴다.
- Claude 앱의 클라우드 세션을 주로 쓴다. → 작업은 바로 push한다 (autosave 훅이 처리).
- 할 일은 Todoist로 관리한다 ("🤗 개인 › AI 공부" 섹션). → 진도·날짜는 Todoist와 맞춘다.
